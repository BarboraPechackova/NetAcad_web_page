# NetAcad Web Pages

This project was created with **Bootstrap 4.3.1**.

## Requirements

### SCSS Installation

To compile SCSS you need **Sass** installed.

- Install locally with npm:

```bash
npm install --save-dev sass
```

### SCSS Compilation
To watch and compile SCSS into CSS, run this command from the project root:

```bash
sass --watch css/style.scss css/style.css
```
